Detailed Project Explanation (3+ minutes)

"My mini-project is called 'Predictive Analysis of Titanic Passenger Survival.'

The problem I'm solving: On April 15, 1912, the Titanic ship sank after hitting an iceberg, and over 1,500 people died. But survival wasn't random — factors like gender, age, ticket class, and how much someone paid for their ticket played a big role in who lived and who didn't. My project uses machine learning to study these patterns and predict whether a passenger would survive, based on their details.

About my dataset: I used a real, publicly available dataset with 891 actual Titanic passenger records, sourced from Vanderbilt University's academic archive — not a fake or made-up dataset. It has 12 columns like age, sex, ticket class, fare, number of family members aboard, and so on. My target variable is 'Survived,' which is either 0 (died) or 1 (survived) — so this is a Supervised Learning Classification problem, since I already know the historical outcomes and I'm predicting a category, not a number.

Exploratory Data Analysis: First, I explored the dataset deeply. I checked the shape, data types, and found missing values — Age had 177 missing, Cabin had 687 missing, and Embarked had 2 missing. I did a correlation analysis and created 8 visualizations, covering univariate, bivariate, and multivariate analysis. From this, I discovered that women survived much more than men, following the 'women and children first' rule, and 1st class passengers survived more than 3rd class passengers, likely due to better access to lifeboats.

Data Preprocessing: Next, I cleaned the data. I filled missing Age values with the median, filled missing Embarked values with the most common port, and dropped the Cabin column since 77% of it was missing. I checked for duplicate rows — found none. I removed outliers in the Fare column using the IQR method, which reduced my dataset from 891 to 775 rows. I also noticed Fare was highly skewed, so I applied a log transformation to normalize it. Then I encoded categorical columns — converting Sex into 0s and 1s, and Embarked into one-hot encoded columns. Finally, I scaled Age and Fare using StandardScaler so no feature would dominate just because of its number size.

Feature Engineering & Selection: I dropped columns that don't help prediction — like PassengerId, Name, and Ticket, since these are just identifiers with no real pattern. Then I used correlation analysis and a statistical method called SelectKBest to rank features by importance. Both methods confirmed that Sex, Fare, and Pclass were the most important predictors of survival.

Model Building: I built and compared four different classification models — Logistic Regression, Decision Tree, Random Forest, and K-Nearest Neighbors. I split my data into 80% for training and 20% for testing.

Model Evaluation: After testing all four models, Decision Tree performed the best, with 78% accuracy and the highest F1-score for correctly identifying survivors. I also discussed potential overfitting risks with Decision Trees, and how Random Forest, which combines multiple trees, is generally more robust — even though it scored slightly lower in my case, likely due to the moderate size of my dataset.

Deployment: Finally, I deployed my best model — the Decision Tree — using Flask, which turns my Python model into a web API. This means someone can send passenger details to my application, and it will return a prediction of whether that passenger would have survived. I also containerized this using Docker, so the entire application can run consistently on any computer, regardless of what's installed on it.

In summary, this project takes a real historical tragedy, applies a complete data science pipeline — from cleaning and exploring data, to building and evaluating machine learning models, to finally deploying a working prediction service — and demonstrates how data-driven approaches can uncover meaningful patterns even in complex, real-world events."
